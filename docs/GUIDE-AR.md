# دليل الاستخدام السريع — نظام JJ's

دليل قصير للإدارة والمدير والموظفين. كل شي بالنظام بالعربي والإنكليزي، وفيك تبدّل اللغة من فوق.

## أول مرة

1. افتح البرنامج → **إعداد النظام**: اسم المحل وحساب الإدارة.
2. **الإعدادات ← العملة وسعر الصرف**: حط سعر الدولار (أو رابط API السعر). بدون سعر ما فيك تبيع بالليرة.
3. **الإعدادات ← المال**: حط الرصيد الافتتاحي للصندوق.
4. **القائمة**: الأصناف والأسعار والوصفات (بالغرام) والتغليف.
5. **الزبائن**: المحلات مع رصيدها القديم ومدة السداد وقائمة أسعارها.
6. **المشتريات ← الموردين**: الموردين مع اللي إلهن علينا.
7. **المستخدمون**: حساب للمدير وللموظفين. المدير والموظف بيشوفوا شاشات بسيطة بأزرار كبيرة، بدون تكاليف وأرباح.

> بدك تجرّب قبل؟ **الإعدادات ← الشبكة والسحابة ← تحميل بيانات تجريبية** (بس إذا القائمة فاضية).

## يوم عادي

| الوقت | مين | شو بيعمل | وين |
|---|---|---|---|
| الصبح | المطبخ | دفعة الإنتاج: كم من كل صنف ← بيشوف المواد ← اعتماد ← طباعة الملصقات | الإنتاج ← دفعة جديدة |
| الصبح | المدير | طلبات المحلات والطلبات الثابتة | الطلبات / التوزيع ← خط التوزيع |
| الطريق | المندوب | ورقة خط التوزيع: كل محل، شو يسلّم، شو يحصّل | التوزيع ← اطبع ورقة التوزيع |
| عند المحل | المندوب | فاتورة (كامل أو جزئي)، أو بضاعة بالأمانة، أو مرتجع | التوزيع |
| المسا | المدير | استلام كاش المندوب، المصاريف، الهدر | الإغلاق اليومي |
| آخر اليوم | المدير | عدّ الصندوق وقفل اليوم | الإغلاق اليومي |
| بأي وقت | الإدارة | "يومك بخمس أجوبة" والتقارير | الرئيسية / التقارير |

## أهم الشغلات

**فاتورة بدفع جزئي:** بالدفع اختار "كاش" واكتب **المقبوض الآن** (مثلاً 400,000 من 600,000). الباقي بيروح على حساب المحل، والفاتورة بتطبع المدفوع والباقي والرصيد.

**بضاعة بالأمانة:** المحل اللي بيدفع بس على المباع بتعلّم عليه "بالأمانة" بصفحته. بتسلّمه البضاعة من **التوزيع ← بالأمانة**. بالزيارة الجاية **تسوية**: بتكتب كم رجع (تالف أو للبرّاد) والنظام بيعمل فاتورة باللي انباع.

**مرتجع:** من **التوزيع ← المرتجعات** أو صفحة الزبون. كل صنف بتختار: رجع للبرّاد أو تالف. المبلغ: رصيد للزبون، أو كاش من الصندوق، أو بدون مبلغ.

**تتبّع دفعة:** إذا صار مشكلة بصنف، امسح باركود الملصق من **الإنتاج ← تتبّع دفعة** وبيطلعلك كل المحلات اللي أخدت منها.

**ارتفع سعر مادة؟** سجّل فاتورة الشراء بالسعر الجديد. **التكاليف ← تغيّر الأسعار** بيورجيك أي سندويشة نقص ربحها وشو السعر المقترح. الفواتير القديمة ما بتتغيّر.

**المصاريف الشهرية:** الإيجار والرواتب بتنحط مرة وحدة بـ **المصاريف ← الشهرية**، وكل شهر بتطلع "مستحقة" لحتى تدفعها.

**السحوبات الشخصية:** مو مصروف. من **الإغلاق اليومي** أو **الإعدادات ← المال ← سحب شخصي**.

**نسخة احتياطية:** تلقائية كل يوم. للاسترجاع: **الإعدادات ← النسخ الاحتياطي ← استرجاع**، وبعدين سكّر البرنامج وافتحه.

## الطابعات والباركود

- طابعة الفواتير: 80 ملم أو 58 ملم، أو A4 (بتختار وقت الطباعة).
- طابعة الملصقات: القياس من **الإعدادات ← الطباعة** (افتراضي 50×30 ملم).
- قارئ الباركود: أي قارئ USB. بشاشة الطلب بتمسح رمز الصنف، وبالبرّاد بتمسح رقم الدفعة.

## الهاتف

- **بنفس الواي فاي:** الإعدادات ← الشبكة ← السماح للهواتف، وبعدين افتح العنوان اللي بيظهر على الموبايل.
